# غرفة الذكاء الاصطناعي — تطبيق أندرويد

1. ارفع محتويات هذا المجلد إلى مستودع GitHub (الفرع main).
2. افتح تبويب Actions وانتظر انتهاء «Build APK» (٥–١٠ دقائق).
3. نزّل الملف `ai-room-apk` من أسفل صفحة التشغيل، وفكّ ضغطه، ثم ثبّت `app-debug.apk`.
4. داخل التطبيق اضغط ⚙ وأدخل مفاتيحك (Gemini وGroq مجانيان). تُحفظ المفاتيح على جهازك فقط.
